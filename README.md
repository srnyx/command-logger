# Command Logger

Log commands executed by players and console to one file or multiple files. TONS of customization for file management, log format, and more!

**🐛 Bugs / 💡 Suggestions:** Please [open an issue](https://github.com/srnyx/command-logger/issues/new/choose) to report a bug or suggest an idea

**🆘 Support:** Please [join the Discord](https://srnyx.com/discord) to get support

## Download

**✅ Stable:** You can download the latest **stable** version at [Modrinth](https://modrinth.com/plugin/command-logger), [Hangar](https://hangar.papermc.io/srnyx/CommandLogger), [Spigot](https://spigotmc.org/resources/126150), [Bukkit](https://dev.bukkit.org/projects/command-logger), or [GitHub](https://github.com/srnyx/command-logger/releases)

**🚧 Snapshot:** You can download the latest **snapshot** version at [github.com/srnyx/command-logger/actions/workflows/build.yml](https://github.com/srnyx/command-logger/actions/workflows/build.yml)
